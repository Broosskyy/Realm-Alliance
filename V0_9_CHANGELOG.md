# REALM ALLIANCE V0.9 — INTEGRATION / UX / VISUAL POLISH

## Unified reward flow
- central RewardService
- one consistent reward modal for Daily, Quests, Lane Attack and Tower Defense
- reward UI is a replaceable production asset

## Unlock flow
- central UnlockService
- Lv.3 Daily, Lv.5 Heroes, Lv.7 Attack, Lv.10 Defense
- one compact unlock banner instead of popup spam
- unlock-seen state is saved

## Daily UX
- Daily Reward is no longer intended as a silent automatic claim
- dedicated large Daily button and claim screen
- explicit claim action
- clear claimed/available state

## Quest UX
First three lightweight tasks:
- 10 monster taps
- 3 wheel spins
- 1 upgrade
All reuse existing actions. No new gameplay rules.

## Visual integration
- Village ambience production slot
- Daily card
- Quest card
- Unlock banner
- Reward modal
- Home/Daily/Quest/Reward icons

## Principle
The six core systems now share progression, rewards and unlock feedback instead
of feeling like separate prototype screens.
