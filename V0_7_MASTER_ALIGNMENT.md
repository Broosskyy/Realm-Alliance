# V0.7 MASTER ALIGNMENT

The Lane Attack implementation follows these constraints:
- target length: approximately 45–90 seconds
- immediately understandable two-lane presentation
- large buttons, no precision placement required
- no requirement to understand deckbuilder terminology
- existing heroes are reused rather than creating another collection system
- attack is optional variety and must not block normal Tap/Village progression
- final art can replace all placeholders independently
- new content should feel different without forcing the player to learn a different game

The current battle numbers are prototype values and are not release balance.
