# REALM ALLIANCE V1.29 — Grünhain Tower Defense Vertical Slice

- Added a lean single-lane Tower Defense slice via Quick Actions.
- HOME / SPIN / DORF remain the primary bottom navigation.
- Player starts with configured energy and may build up to two towers.
- Towers deal deterministic damage; three increasingly durable waves form the P0 run.
- Cleared waves grant one energy to support the short build/defend loop.
- Completing wave 3 grants the configured reward exactly once; completed state persists.
- Wave, energy, tower count, enemy HP and completion state persist in Save Schema V20.
- Added TD telemetry for tower build, wave clear and run completion.
- Current castle/tower/enemy glyph presentation is integration scaffolding, not final art.
- Lane Battle remains disabled for the next vertical slice.
- V1.23–V1.28 systems remain preserved.
- Website remains excluded.
