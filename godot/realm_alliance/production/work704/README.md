# Mockup Test 704 art

The recovered moss golem sheet is the six-pose asset generated earlier in this conversation and restored from the saved file. `normalize.py` isolates complete connected alpha components before slicing; punches cross nominal cell boundaries. It preserves original alpha, uses one scale across all poses, and grounds every frame on a shared pivot. Standing alpha bounds are baked into production_enemy.gd; no GPU readbacks occur during layout.

The UI sheet and six-pose armored guardian outfit were created with the built-in image generation tool using the supplied white-haired hero / collection master boards as style references. Original PNG sheets are retained under sources. Armor socket metadata records the transformed fist, forehead and chest positions for every pose. The weapon remains a separate sprite. No gameplay or fake interface is baked into these images.

This folder is excluded from player exports. Its runtime PNGs, metadata and complete fonts are in assets/work704 and assets/ui/work61/fonts. The complete font binaries resolve missing star/arrow glyphs in the old subset.

This source is based on the recovered 702 continuous-weapon-track candidate. It does not contain the lost 7.5 source branch. The Android application ID is deliberately separate so that an existing newer preview and its saves are preserved.
