# Realm Alliance V0.4 Source

## Added
- HeroSystem autoload
- 3 data-driven starter heroes
- account-level based unlocks
- hero level + clear Strength value
- simple gold upgrades
- automatic combined hero DPS
- hero save/load integration
- lightweight Heroes screen
- master-concept simplicity contract
- heroes.json content definition

## Preserved
- Tap gameplay
- 8-segment wheel
- village upgrades
- daily rewards
- save game
- progression/economy
- shop/payment abstraction
- Region 1 data

## Product rule
More depth must not mean more visible complexity.
V0.4 deliberately avoids inventory, shards, skill trees and stat overload.
