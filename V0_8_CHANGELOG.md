# REALM ALLIANCE V0.8 — TOWER DEFENSE FOUNDATION

## Tower Defense
- unlock at Account Lv. 10
- ~55 second target duration
- one fixed readable route concept
- automatic tower attacks
- waves spawn automatically
- player has one simple active choice: strengthen towers
- shared energy resource inside the short mode
- village-core HP
- Gold + XP reward on success
- no free tower placement and no micro-management

## Lane Attack polish
- lane push state now moves player unit markers toward the enemy
- visual feedback is driven by battle state rather than static art
- existing two-button interaction is retained

## Visual production
New replaceable slots:
- Greenvale TD map
- Archer tower
- Mage tower
- Runner enemy
- Tank enemy
- projectile
- tower-hit FX
- Gold Mine Lv.2
- Forge Lv.2
- Defense Tower Lv.1
- alternate Greenvale boss slot
- Defense navigation icon

## Production principle
V0.8 adds visual/content depth without adding another complex collection,
placement or stat-management layer.
