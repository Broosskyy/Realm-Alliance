# REALM ALLIANCE — Game Source Scope

This package is the game source only.

Included:
- Godot runtime/gameplay
- game UI/HUD
- save/config/economy
- game assets and placeholders
- Android and game-preview/export configuration
- QA/validation tools

Excluded:
- public website
- website CMS/admin portal
- website support/news/wiki/status implementation
- standalone web-platform source

Those are developed in a separate workstream/chat.
