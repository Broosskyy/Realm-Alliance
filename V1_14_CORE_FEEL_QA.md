# V1.14 CORE FEEL QA

## Home/Tap
- Tap rapidly: every accepted tap must lower HP correctly.
- HP bar should ease quickly but never lag enough to feel disconnected.
- Damage number should remain readable and vary slightly in position.
- Monster should squash/recover on hit and breathe subtly while idle.
- Reduced Motion must remove movement while retaining readable damage feedback.

## Touch
- HOME, RAD, DORF, RAD DREHEN, DREHEN, WEITER, VERBESSERN and ABHOLEN should visibly react to finger-down/up.
- Touch feedback must not resize/reflow the layout.

## Rewards
- Monster reward should appear quickly and clearly.
- Wheel reward should have the same restrained feedback language.
- No reward animation may unlock background input early.

## Regression
- Run monster transaction QA from V1.13.
- Run Wheel/Village rapid-tap tests.
- Run 720x1600, 1080x1920 and tall-phone layouts.
- P1 remains disabled until real device Core PASS.
