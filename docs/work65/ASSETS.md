# Production asset record — Work 6.5

Built-in image generation was used; no external asset licensing or paid-provider key was required. The equipment/hero identity remains the canonical white-haired masked Realmwächter. Original production body, hand/weapon sockets, five swords, golem states and Wolkgarten plate are preserved.

## New files and use
- `assets/enemies/ember_boar/{idle,attack,hit,defeated}.png`: four independent 512×512 RGBA sprites used by actual Glutkeiler normal encounters and double-strike Aschenhauer elite. One four-state sheet provides shared anatomy, palette, view and lighting. All use feet pivot (256,480) and one common uniform scale, rather than fitting each pose independently. Technical extraction uses alpha bounds >8 to ignore negligible sheet-edge noise; source alpha within the bounds is retained. No VFX is baked into these sprites.
- `assets/world65/glutkern.webp`: actual second-region combat backdrop, downsampled to 768×1152, opaque WebP quality 90.
- `assets/world65/world_map.webp`: illustrated two-region map on Adventure, downsampled to 1200×800, opaque WebP quality 90. Regions/stage controls are live native nodes, not baked into the illustration.
- `assets/world65/ember_palette.gdshader`: separate palette for basalt enemy and Aschenkoloss, preserving canonical golem pose geometry/alpha. Eruption and aftershock use real EnemyBehavior deadlines; warning ring and impact remain separate VFX.

File hashes, source identifiers and extraction scale/bounds are in `assets/world65/manifest.json`. Raw generation output is retained separately in the working session; the shipped source includes normalized game-ready assets and provenance.

## Generation prompts

### Boar four-state sheet
Use case: stylized-concept. Production game asset for REALM ALLIANCE, painted premium 2.5D mobile fantasy RPG, consistent with a white-haired black/gold masked guardian and hand-painted stone golem. Create ONE coherent enemy sprite sheet with FOUR isolated states of the SAME creature, in a strict 2 by 2 grid, square canvas. Creature: a stout volcanic wild boar, dark slate armored hide, restrained ember cracks, gold-copper tusk bands, small warm orange eyes; three-quarter SIDE view facing LEFT toward the hero. Top-left: idle/ready, all four feet grounded. Top-right: attack, low charging lunge with tusks forward. Bottom-left: hit reaction, recoiling with head raised slightly. Bottom-right: defeated, lying on side on ground, visibly different silhouette. Same anatomy, colors, size and lighting across all four states. Each occupies its own equal cell with generous transparent margins and no overlap across cells. Entire creature visible including all feet, tail and tusks. No embedded flames, particles, slash trails or hit effects; these are separate in-engine layers. Actual transparent alpha background, including gaps between legs. No ground plane, cast shadow, environment, frames, UI, labels, lettering, numerals, watermark or checkerboard. Sharp clean cutout contours with painterly detailed materials.
