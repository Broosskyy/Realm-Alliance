This is the Master V1.4 gate before P1.

## 5-minute test
Player should understand tapping the monster without explanation.
Monster Hit -> Defeat -> Reward must feel immediate.
Wheel CTA must be obvious after returning Home.

## 15-minute test
Player must have used Wheel and Village naturally.
At least one building upgrade should feel meaningful.
5/10 milestone and direction toward Boss must be understood.

## 30-minute test
Boss should be reached without another system being required.
Goldmine/Forge/Luck Temple effects must be understandable.
Player should want another Monster -> Reward -> Wheel -> Village loop.

## Return test
Close/background app, return later.
Gold, Spins, monster HP/progress, village levels and settings persist.
Goldmine elapsed production persists.
No duplicate kill/wheel/building reward occurs.
Backup recovery must not destroy the previous valid save.

## Mandatory gate
