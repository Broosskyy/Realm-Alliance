# V0.8 MASTER CONCEPT ALIGNMENT

Tower Defense follows the product contract:
- short understandable defense sequence
- fixed paths
- towers/heroes work automatically
- few large actions
- no precision placement
- no tower-management spreadsheet
- mode reuses the existing account/economy progression
- normal solo progression remains possible without mastering the mode

Player-facing complexity:
1. See enemies coming.
2. Watch towers attack.
3. Press one large upgrade action when enough energy exists.
4. Protect the village until the timer ends.

Internal systems may later support more wave sets, enemies, towers, rewards,
events and remote balance, while this simple interaction remains stable.

All balance values remain prototype/playtest values.
