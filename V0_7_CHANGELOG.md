# REALM ALLIANCE V0.7 — LANE ATTACK FOUNDATION

## First playable mini-mode foundation
- Lane Attack unlocks at Account Lv. 7
- 60-second target session
- two lanes
- one simple action: deploy a hero left or right
- shared energy meter
- enemy-base HP
- passive enemy pressure
- win reward in Gold + XP
- no deckbuilding, no drag/drop precision, no complex unit stats

## Visual production slots
- Greenvale lane map 1080×1500
- Knight, Archer and enemy unit sprites
- monster hit overlay
- monster death overlay slot
- Town Hall visual Lv. 2 and Lv. 3
- attack navigation icon slot
- all assets remain replaceable without gameplay rewrite

## Visual progression
Town Hall now changes its actual art slot at village milestones instead of only changing a number.

## Core Feel
Manual taps have a fast hit-flash overlay.
Lane combat stays readable and intentionally slower than twitch PvP.

## Existing systems retained
Tap / bosses / weighted Wheel / village / heroes / Auto-DPS / Daily / Save / economy / payment abstraction.
