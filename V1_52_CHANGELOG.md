# REALM ALLIANCE V1.52 — Quests, Achievements & Collections V2

- Added a persistent cross-pillar ObjectiveSystem instead of another gameplay mode.
- Three UTC-daily objectives and three weekly objectives with deterministic period buckets.
- Five persistent achievements spanning Combat, Journey, Puzzle, Tower Defense and Lane Battle.
- Grünhain Bestiary collection tracks unique defeated production encounter IDs.
- Claims grant existing Gold, Spins and Realm Keys only; no new currency.
- Hooks added to authoritative monster defeat, successful Spin, Journey lap, Puzzle completion, Tower Defense completion, Lane Battle victory and Village upgrade.
- Existing V1.32 starter quests remain compatible but the visible task hub is now the V1.52 objective structure.
- Objective hub is scrollable and mobile-first.
- Objective state is persisted; daily/weekly period changes reset only their own progress/claims.
- Global Progression Overview includes Bestiary/objective status.
- Added exactly eight isolated transparent 768×768 objective/collection placeholders.
- Save schema remains V20.
